## Editor settings

1. Once the Canva slides exist and have been reviewed, export all eight pages as PNG, preferably 1920×1080 or higher. Import them in numerical order.
2. Set each image's duration using the table. Use clean cuts so the timeline remains exactly 60 seconds. Apply a gentle 100% to 104% zoom only if the image remains safely inside the frame.
3. Add narration using `narration.txt`. Read at a relaxed pace, with a pause at each paragraph. Align each paragraph to its corresponding slide. The last paragraph needs a slightly faster delivery.
4. Import `captions.srt`. These timings follow the planned narration, not an existing recording. Align them to the actual audio before export.
5. Choose a warm instrumental without vocals, licensed for commercial and fundraising use. Start the music around 15–20 dB below the voice and adjust by ear. Fade it in and out over one second.
6. Export H.264 MP4, 1080p, 30 fps. Watch the complete export once to check readability, audio balance, and caption timing.
